# FitPulse — Agent Session Log

## Project Overview

AI-powered fitness tracker with Flutter web frontend + FastAPI backend.

- **Frontend:** `fitpulse/` — Flutter 3.44.1, web-only, Riverpod + go_router
- **Backend:** `backend/` — FastAPI, Gemini Vision, USDA Food Data Central proxy
- **Deploy:** Railway (backend) + Firebase Hosting (frontend)
- **Image hosting:** Cloudinary (unsigned upload preset)
- **Live URL:** https://fitpu1se.web.app

## Useful Commands

```bash
# Backend (local)
cd backend
.venv\Scripts\activate
uvicorn main:app --reload --port 8000

# Frontend
cd fitpulse
flutter pub get
flutter analyze
flutter build web
flutter run -d chrome

# Deploy frontend
cd fitpulse
firebase deploy --only hosting

# Railway (backend deploy)
cd backend
railway login --browserless
railway up
railway redeploy --yes
```
